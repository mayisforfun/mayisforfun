GRAY_PWM：五路灰度循迹小车

本工程面向电赛小车快速验证：MSPM0G3507 + 五路数字灰度 + TB6612 差速驱动。

先看当前状态

  • main.c 默认 MOTOR_DIAGNOSTIC_MODE = 1，下载后只做电机正反转诊断，不会循迹。
  • 要跑循迹，把 MOTOR_DIAGNOSTIC_MODE 改成 0 后重新编译下载。
  • 控制周期当前为 100 Hz，即 10 ms 一次。
  • 编码器、速度 PID、赛道状态机、MPU6050 已有模块，但默认主循环尚未接入。

关键核对

项目默认设置
灰度A26/A27/A24/A25/B24，对应 L2/L1/C/R1/R2
PWMA12 = TIMG0_C0，A13 = TIMG0_C1，period/load = 1000
电机A 通道左电机，B 通道右电机
黑线电平GRAY_BLACK_IS_LOW = 1
